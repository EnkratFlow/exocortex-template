# Subconscious Pattern Architecture

The subconscious tier searches project-local narrative evidence for recurring
friction, repeated explanations, candidate skills, durable memory facts, and
missing context. It is a retrospective aid, not an autonomous actor.

Default execution is local and provider-neutral. The active conversation model
may reason over files already authorized for reading. Direct provider, RAG,
MCP, hub, vault, credential, or network access is disabled.

Outputs are prospective proposals with evidence references and confidence.
They do not mutate memory, create skills, capture interrupts, alter lifecycle
state, acquire a writer, or authorize external action. Each accepted proposal
becomes a new bounded work item with its own approval, isolated lane, tests,
Human UAT, and promotion gate.

This separation is the recursive-improvement safety property: the system can
identify how to improve itself without granting its own recommendations the
power to execute.
