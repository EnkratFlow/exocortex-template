# Project-Local Memory Tiers

Exocortex organizes existing project-local events into four views:

| Tier | Range | Purpose |
|---|---|---|
| Right now | 0–7 days | vivid current context |
| Short term | 7–31 days | recurring recent themes |
| Long term | 31+ days | compressed durable history |
| Subconscious | all evidence | cross-cutting patterns and improvement proposals |

The active conversation model may summarize these files without any key or
network access. Legacy scripts never discover credentials or call a provider.
External provider-assisted curation requires an immutable local payload and a
separate exact egress authorization.

Memory is evidence, not authority. Generated summaries can be stale; reconcile
them against live Git, the exact work item, and project-local events. A pattern
review creates prospective recommendations only and cannot approve or execute
its own recursive improvement.

Events remain project-local unless the owner separately approves one exact
descriptor and destination. Memory never flows sideways between repositories.
