# Workflow Command Reference

Read `AI_START_HERE.md`, then `.exocortex/AI_BOOTSTRAP.md`, then the exact JSON
specification in `.exocortex/commands/`.

- Daily: `/work`, `/scrum`, `/save`, `/daily-end`, `/interrupt`, `/brief`
- Memory: `/shortterm`, `/longterm`, `/subconscious`, `/drill`, `/history`
- Planning: `/groom`, `/refine-backlog`, `/prioritize`, `/weekly-review`,
  `/monthly-review`, `/pattern-review`
- System: `/onboard`, `/system-scan`, `/ai-export`, `/ecosystem`,
  `/init-exocortex`, `/check-keys`, `/handoff`

All commands default read-only. Mutation language is a proposal until an exact
current capability is accepted by the registered guarded executor. External
sync is always a separate destination-specific gate.

`/save` is narrative memory, not a checkpoint. `/handoff` is evidence, not
authority. `/pattern-review` proposes recursive improvements but cannot execute
them. The phase hook is only a reminder to consider an authorized local save.
