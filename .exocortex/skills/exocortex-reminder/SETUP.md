This file intentionally contains no executable SSH, SCP, cron, OpenClaw, or
Telegram commands. Those actions affect an external machine or service and are
outside the project-local Exocortex guard.

If the owner wants this integration later, prepare a separate proposal that
names all of the following before any connection or mutation:

1. exact external host and accountable operator;
2. exact files and destination paths;
3. schedule, timezone, message, and recipient class;
4. transport and credential boundary;
5. one-time setup effect and ongoing Telegram egress effect;
6. disable/remove procedure, verification, and rollback;
7. destination-specific approval and a transport adapter capable of enforcing
   it.

An AI must then stop and request the separate external-system authorization.
Approval to edit a repository, install Exocortex, or record a local save does
not authorize any part of this setup. Until an approved OpenClaw/SSH transport
adapter and its tests exist, the owner performs any setup manually outside this
repository protocol.
